# Design Principles

These notes describe patterns visible in the current site.

- **Municipal identity:** official seal, Consolacion-specific copy, and a consistent site header/footer.
- **Readable hierarchy:** Domine for prominent headings; Geist for body text; clear page titles and descriptive link labels.
- **Color roles:** blue primary, coral secondary, green success, and gold warning. Use color with text and icons rather than as the only signal.
- **Responsive by default:** navigation collapses on small screens; tables scroll horizontally; page sections adapt from single-column to multi-column layouts.
- **Accessible interaction:** semantic headings and landmarks, skip link, focus-visible outlines, descriptive labels, and large touch targets.
- **Public information clarity:** mark illustrative imagery and be explicit when a public record is only a title index or lacks an official document.

Tokens and UI defaults are defined in `frontend/app/assets/css/main.css` and `frontend/app/app.config.ts`.
