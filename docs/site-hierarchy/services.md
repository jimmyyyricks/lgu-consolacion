# Services

Location: `/#services`, the services section on the homepage.

The section is a searchable directory of eight links:

| Link | Destination |
| --- | --- |
| Forms and applications | [Downloadable forms](transparency.md) |
| Government updates | [Government actions](about-page.md) |
| Ordinances | [Transparency records](transparency.md) |
| Resolutions | [Transparency records](transparency.md) |
| Bids and awards | [Transparency records](transparency.md) |
| Full disclosure | [Transparency records](transparency.md) |
| News and announcements | [News](news-tourism.md) |
| Tourism information | [Tourism](news-tourism.md) |

The list is defined in `frontend/app/utils/services.ts`. It is a navigation directory, not a separate online transaction system.
