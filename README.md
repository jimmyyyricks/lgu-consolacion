# LGU Consolacion Website

The official website for the Municipality of Consolacion, Cebu. It provides municipal services and information, government updates, tourism content, and public records, alongside a staff content-management workspace.

## Stack

- Frontend: Nuxt 4, Vue 3, Nuxt UI, TypeScript
- Backend: Python, FastAPI, SQLAlchemy
- Database: PostgreSQL in production; SQLite for development and tests
- Package managers: pnpm (frontend), pip (backend)

See [`docs/`](docs/) for project documentation. The website route map is in [`docs/site-routes.md`](docs/site-routes.md).
Production build and server deployment instructions are in [`docs/deployment.md`](docs/deployment.md).
